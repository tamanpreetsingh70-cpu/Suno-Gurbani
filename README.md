# Suno Gurbani

A responsive, mobile-first starter website for a Sikh spiritual practice companion.

## Preview locally
Open `index.html` in a modern browser, or serve the repository with any static web server.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and the `/(root)` folder, then save.
4. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Included in this starter
- Responsive landing page and mobile navigation
- Search/filter for a starter list of bani names
- Naam Simran counter with browser-local persistence and configurable goals
- Sehaj Path Ang progress tracker (1–1430), stored locally
- Gregorian date display and daily practice checkbox
- Sikh history learning cards and basic privacy/terms/disclaimer pages
- Accessibility-minded labels, focus states, and responsive layout
- Footer credit: Made with devotion by Tamanpreet Singh

## Important limitations
This is a functional **static starter**, not yet a complete production Gurbani platform. The starter does not include a verified full Gurbani database, complete 1430-Ang text, official daily Hukamnama integration, Nanakshahi date conversion, licensed audio/live Kirtan, authentication, cloud database, admin dashboard, or AdSense approval. Connect authoritative sources and confirm permissions before publishing sacred texts or media. Never present placeholder content as official or verified.

The Simran count, progress, and daily checkbox are stored in the visitor's browser using localStorage. Clearing browser storage resets that local data. No server-side account or profile exists.

## Development notes
No build tool or dependency installation is required for the current single-file version. The website source is `index.html`. Keep any future API keys and private credentials out of client-side code.
